# Non functional requirement

This is a tech document on how to implement this project.

* This project uses Flutter for web.
* This project uses BLOC for state management
* You are a specialist on clean code development, knows SOLID principle and other good development practices
* This project allows the user to:
  * Import and export TV Shows data from a CSV file
  * Edit TV Shows information
  * Import movies from a CSV file
  * Check data inconsistencies on imported Movies Letterboxd diary file
* Create or update a Makefile file to build and run the project. The Makefile should have at least the following commands:
  * `make build` - builds the project
  * `make run` - runs the project
  * `make test` - runs the tests
* Create PowerShell Scripts to perform the same things as the Makefile commands. The scripts should be named `build.ps1`, `run.ps1`, and `test.ps1`.
* Create or update a README.md file with instructions on how to build and run the project, as well as how to run the tests.
* For every implemented task, keep a track on a separate file named `tasks.md` with the following information:
  * Task description
  * Date of implementation
  * Any relevant notes or comments
