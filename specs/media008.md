# Movie Tags Statistics

## Description

Create a bar on the movie screen that shows the statistics.

Example:

```
9999 EMPTY TAGS
9999 INVALID FORMAT
9999 NON UNIQUE SOURCE TAG
9999 NON UNIQUE TMDB_ID TAG
9999 MISSING GENRE TAG
9999 VALID TAGS
```
