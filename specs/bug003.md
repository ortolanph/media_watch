# Replace Clipboard reports

Replace Clipboard reports to mustache reports.

1. TagValidationBarWidget
2. TagWidget

## Library

`mustache_template: ^2.0.6`

## TagValidationBarWidget

Template:

```
# {{key}}

{{#values}}
* {{.}}
{{/values}}
```

## TagWidget

Template:

```
label,description,{{timestamp}}
{{#validation}}
{{label}},{{description}},{{quantity}}
{{/validation}}
```
